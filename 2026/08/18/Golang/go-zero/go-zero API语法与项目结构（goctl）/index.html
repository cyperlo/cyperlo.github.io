2.2 参数标签大全（重要）

标签 用途 示例
path URL 路径参数 Id int64 \path:”id”``
form Query/表单参数 Keyword string \form:”keyword”``
form,default=1 Query 参数带默认值 Page int \form:”page,default=1”``
form,optional 可选参数 Remark string \form:”remark,optional”``
json JSON Body 参数 Name string \json:”name”``
json,optional 可选 JSON 参数 Age int \json:”age,optional”``
header 请求头参数 Token string \header:”Authorization”``

default 与 optional 的区别：

  • default=1：不传时用默认值 1
  • optional：不传时是零值，不会报参数错误
  • 都不加：必传参数，不传直接 400 报错

常用规则：

规则 含义
required 必填
min=4,max=20 长度范围
email 邮箱格式
gte=0,lte=150 数值范围
oneof=a b c 枚举值
omitempty 空值跳过校验

3. service 定义详解

3.1 路由分组与 @server 块

@server 块支持的关键字：

关键字 作用
jwt: Auth 该分组接口需要 JWT 鉴权（Auth 是 key 名）
group: user handler 按组拆分文件（userhandler.go）
middleware: Xxx 绑定自定义中间件
timeout: 3s 接口超时时间
maxBytes: 1048576 请求体大小限制
prefix: /v1 路由前缀
