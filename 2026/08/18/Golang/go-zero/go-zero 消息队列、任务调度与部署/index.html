2. 任务调度（asynq）

2.1 asynq 是什么

asynq 是 go-zero 社区常用的分布式任务队列（基于 Redis），支持：

  • 延迟任务（如：订单 30 分钟未支付自动关闭）
  • 定时任务（如：每天凌晨 2 点生成报表）
  • 任务重试、优先级、去重

5. 系列总结与进阶路线

至此，go-zero 从入门到中级的内容已经全部覆盖：

章节 掌握能力
第 1 章 go-zero 概念、环境搭建、第一个 API 服务
第 2 章 .api DSL 完整语法、goctl 高级用法、参数校验
第 3 章 JWT 认证、自定义中间件、从 token 取用户信息
第 4 章 proto 定义、RPC 服务、etcd 服务注册发现、服务互调
第 5 章 model 生成、缓存一致性、事务、Redis 实战
第 6 章 限流、熔断、降载、超时、链路追踪、监控
第 7 章 Kafka 异步、asynq 任务调度、Docker/K8s 部署

进阶方向（达到高级水平）：

  1. 秒杀系统：分布式锁 + 消息队列削峰 + 库存预扣
  2. 分布式事务：Seata / 本地消息表 + 最终一致性
  3. 多级缓存：本地缓存（ristretto/bigcache）+ Redis + 数据库
  4. 读写分离 / 分库分表：sharding-sphere / shardingsphere-go
  5. 压测与调优：pprof、wrk/k6 压测、GC 调优
  6. 服务网格：Istio 平滑接入
