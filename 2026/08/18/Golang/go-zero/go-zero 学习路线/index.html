go-zero 学习路线（系列导读）

本文是本系列教程的总入口，建议先读这篇，再按顺序学习后续文章。
系列目标：0 基础入门 → 中级水平（能独立开发、部署一个完整的 go-zero 微服务项目）

1. 系列概览

本系列共 7 篇文章，以「用户服务」为贯穿案例，从环境搭建到生产部署形成完整闭环。全部基于 go-zero 最新稳定版本编写，所有代码示例均可在本地直接运行。

阶段 篇目 一句话总结
入门 第 1 篇 认识 go-zero，跑通第一个 API 服务
核心 第 2 篇 吃透 .api 语法，熟练使用 goctl 神器
核心 第 3 篇 实现完整的 JWT 用户认证与中间件
核心 第 4 篇 API + RPC 微服务拆分，etcd 服务发现
进阶 第 5 篇 数据模型与缓存一致性方案
进阶 第 6 篇 限流、熔断、链路追踪等治理能力
实战 第 7 篇 消息队列、任务调度、Docker/K8s 部署

3. 文章目录与学习要点

📖 第 1 篇：go-zero 框架介绍与快速入门

  • 定位：系列起点，回答「go-zero 是什么、为什么选它」
  • 核心知识点：框架特性、与 Gin/Go Micro 等对比、环境搭建、goctl 安装、goctl api new 创建第一个服务、目录结构解析
  • 动手任务：本地创建并启动一个 hello 服务，访问接口返回 JSON
  • 前置要求：Go 1.21+ 基础语法（变量、函数、结构体、net/http）

📖 第 2 篇：go-zero API 语法与项目结构（goctl）

  • 定位：吃透 .api 文件 DSL，这是 go-zero 开发的核心技能
  • 核心知识点：service/handler/type 语法、参数标签（path/form/json/header）、validate 校验、@server 块、goctl 高级命令（goctl api go/validate/doc）
  • 动手任务：手写一个包含 GET/POST、路径参数、表单校验的完整 .api 文件并生成代码
  • 前置要求：第 1 篇

📖 第 3 篇：go-zero 用户认证与中间件实战（JWT）

  • 定位：几乎所有业务系统的第一个真实需求
  • 核心知识点：注册/登录流程、bcrypt 密码加密、JWT 签发与校验、jwt: Auth 语法、自定义中间件（全局/路由两种方式）、从 JWT 提取用户信息
  • 动手任务：为服务加上注册、登录、鉴权接口，未登录访问返回 401
  • 前置要求：第 1~2 篇

📖 第 4 篇：go-zero RPC 微服务开发与服务发现

  • 定位：进入真正微服务架构的关键一役
  • 核心知识点：gRPC/proto 语法、goctl rpc 生成代码、etcd 注册与发现原理、API 服务调用 RPC 全流程、RPC 拦截器（自定义/日志/限流）
  • 动手任务：把用户服务拆成 user-api + user-rpc，通过 etcd 完成服务间调用
  • 前置要求：第 1~3 篇，了解基本 gRPC 概念

📖 第 5 篇：go-zero 数据模型与缓存

  • 定位：补齐数据库访问层，让业务真正落库
  • 核心知识点：goctl model 根据建表语句生成代码、sqlx 使用、单表/联表 CRUD、缓存一致性（Cache Aside）、事务、缓存穿透/击穿/雪崩防护
  • 动手任务：设计一张用户表，生成 model 代码，实现带缓存读写的接口
  • 前置要求：第 4 篇，了解 MySQL 与 Redis 基本操作

📖 第 6 篇：go-zero 微服务治理（限流、熔断、链路追踪）

  • 定位：go-zero 最大的卖点，生产环境的稳定性保障
  • 核心知识点：限流三件套（MaxConns 并发控制、令牌桶 TokenLimiter、PeriodLimit 滑动窗口）、自适应熔断（Breaker）、超时控制、降载保护、OpenTelemetry + Jaeger 链路追踪、Prometheus 指标监控
  • 动手任务：为服务开启限流与熔断，配置 Jaeger 查看调用链
  • 前置要求：第 4~5 篇

📖 第 7 篇：go-zero 消息队列、任务调度与部署

  • 定位：生产落地收尾，异步化 + 上线
  • 核心知识点：Kafka 生产者/消费者（go-queue）、asynq 延迟任务/定时任务、goctl docker 一键镜像、K8s 部署清单编写、环境变量与配置管理
  • 动手任务：把「注册成功后发欢迎消息」改成异步消息，最后用 Docker 部署整个服务
  • 前置要求：第 5~6 篇

4. 环境准备清单

学习前请确认以下环境（第 1 篇有详细安装步骤）：

工具 版本要求 用途
Go 1.21+ 开发语言
goctl 最新版 代码生成神器
MySQL 5.7+ 业务数据存储
Redis 5.0+ 缓存 / 限流
etcd 3.4+ 服务注册与发现
Docker 任意 中间件一键启动
Jaeger / Kafka（可选） - 链路追踪 / 消息队列

偷懒方案：用 Docker Compose 一键启动 MySQL、Redis、etcd、Jaeger 等所有中间件，第 1 篇附带了完整配置。

5. 学习建议与进度跟踪

5.1 学习建议

  1. 边看边敲：不要只读代码，务必动手创建项目、运行接口，代码只有跑起来才算学会
  2. 善用 goctl：go-zero 是「代码生成优先」的框架，遇到重复劳动先想 goctl 能不能生成
  3. 按顺序学：第 2 篇的 .api 语法是后续所有篇目的基础，不要跳
  4. 对照官方文档：每篇文末都附了官方文档链接，遇到细节问题以官方为准
  5. 关注版本：go-zero 迭代很快，遇到与文中不一致的 API 时先 goctl -v 检查版本

6. 常见问题（FAQ）

Q：没有微服务经验，能直接学这个系列吗？
A：可以。系列从单体 API 服务讲起，第 4 篇才开始引入 RPC 拆分，前 3 篇只需 Go 基础。

Q：必须要安装 etcd / MySQL / Redis 吗？
A：前 3 篇只需要 Go 环境；第 4 篇起需要 etcd，第 5 篇起需要 MySQL/Redis，建议提前用 Docker 装好。

Q：学完这个系列能达到什么水平？
A：中级水平——能独立完成一个带认证、缓存、限流、可观测的 go-zero 微服务项目，并部署上线。

Q：学完之后想继续深入，往哪个方向走？
A：见下方进阶路线。

7. 进阶路线（中级 → 高级）

完成本系列后，可向以下方向继续深入：

  1. 分布式事务：go-zero 支持的 Saga / TCC 方案，以及 seata 集成
  2. 容器化进阶：K8s 弹性伸缩（HPA）、服务网格（Istio）、蓝绿发布
  3. 多语言网关：gRPC-Gateway、统一 API 网关层设计
  4. 性能调优：pprof 性能分析、GC 优化、连接池调优、压测实践
  5. 源码阅读：研读 go-zero 核心源码（core 目录下的 breaker、limiter、syncx 等），理解设计哲学
  6. 云原生：对接云厂商中间件（云 MySQL、云 Redis、消息队列托管版）
