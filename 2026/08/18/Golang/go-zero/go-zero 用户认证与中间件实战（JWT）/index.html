1. JWT 基础概念

JWT（JSON Web Token）由三部分组成，用 . 连接：

  • header：算法信息（如 HS256）
  • payload：业务数据（如 userId、过期时间）
  • signature：签名，用于防篡改

go-zero 内置了 JWT 支持，在 .api 文件的 @server 块中声明 jwt: Auth 即可开启，框架会自动完成 token 的解析与校验。

7. 扩展：刷新 token 方案

Access Token 有效期短（如 2 小时），过期后需要刷新。常见做法：

  1. 登录时同时签发 AccessToken（短）和 RefreshToken（长，存 Redis）
  2. 当 AccessToken 过期时，前端用 RefreshToken 调用 /user/refresh 换新 token
  3. RefreshToken 支持主动失效（如注销登录、踢人下线）
