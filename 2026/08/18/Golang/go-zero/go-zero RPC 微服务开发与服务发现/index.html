go-zero RPC 微服务开发与服务发现

微服务架构的核心是服务间的通信。go-zero 基于 gRPC 实现 RPC 通信，并内置 etcd 服务注册与发现。本章我们实现一个经典的微服务场景：

1. 核心概念

概念 说明
gRPC Google 开源的高性能 RPC 框架，基于 HTTP/2 + Protobuf
protobuf 跨语言的序列化协议，接口定义语言（.proto 文件）
etcd 分布式键值存储，这里用作服务注册中心
zrpc go-zero 对 gRPC 的封装，屏蔽了连接管理、重试等细节

架构理解：

  • API 服务（user-api）：面向客户端的 HTTP 入口
  • RPC 服务（user-rpc）：内部业务服务，启动时自动注册到 etcd
  • 调用方通过 etcd 发现服务地址，动态建立 gRPC 连接
